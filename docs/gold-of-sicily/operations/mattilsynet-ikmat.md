# Mattilsynet og IK-Mat

Gjelder **Gold of Sicily AS**. Holdingselskapet skal ikke ha denne listen.

I appen speiles dette av playbooken **Food Safety** (kun driftsselskap). Last opp logger og bekreftelser som evidens der.

## Registrering

- [ ] Registrere matvirksomheten hos Mattilsynet før oppstart.
- [ ] Beskrive / få på plass produksjonslokale (hygiene, vann, avfall, skadedyr).

## IK-Mat (hygiene)

- [ ] Skriftlige rutiner (HACCP-basert): mottak, tilberedning, steking, nedkjøling, oppbevaring, utlevering.
- [ ] Temperaturmåling: frityrolje / kjerne / kjøl / frys — med logg.
- [ ] Renhold og personlig hygiene.
- [ ] Avvik og tiltak.

## Sporbarhet og merking

- [ ] Kunne spore råvarer ett steg bakover og ferdige varer ett steg frem.
- [ ] Allergener og merking på ferdig pakning (forordning (EU) nr. 1169/2011).
- [ ] Holdbarhet og oppbevaringsbetingelser.

## Bevis (lastes opp i appen, ikke git)

Temperaturlogger, Mattilsynet-bekreftelse, IK-Mat-rutiner, batchlogger, etikettmal.
